## Featured Projects

### LLM Next-Message Prediction

Research and development project focused on fine-tuning transformer-based language models to predict the next human message in multi-participant conversations.

The project includes:

* conversational dataset preprocessing;
* transformer model fine-tuning;
* baseline and fine-tuned model comparison;
* LoRA and parameter-efficient training;
* automatic and classifier-based evaluation;
* analysis of generated responses.

### Machine Learning Ticket Classification API

An end-to-end machine learning application for classifying support tickets.

The project includes:

* text preprocessing and feature engineering;
* model training and evaluation;
* FastAPI inference service;
* Pydantic request validation;
* REST API endpoints;
* reproducible training and prediction workflows.

### Car Price Prediction

An end-to-end regression project for predicting vehicle prices using structured automotive data.

The project covers:

* exploratory data analysis;
* missing-value handling;
* leakage-safe data splitting;
* preprocessing pipelines;
* model comparison;
* cross-validation;
* error analysis.
